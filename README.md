# MapNinja map corrections

Found a misplaced pin, a missing location, or directions that led you to the wrong spot on [MapNinja](https://www.mapninja.io/)? This is where players can report it.

1. [Check existing reports](https://github.com/Map-Ninja-io/map-corrections/issues) to see if someone has reported the same location. If so, add what you found there.
2. [Report a map correction](https://github.com/Map-Ninja-io/map-corrections/issues/new?template=map-correction.yml). Paste the map link, name the pin or a nearby landmark, and explain what you found in the game.
3. If the location is hard to describe, attach an in-game screenshot and mention the floor or region.

For a missing pin, tell us what should appear there. For a misplaced pin, describe where it appears now and where it belongs.
